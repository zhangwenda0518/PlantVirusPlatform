# 结果图整理（内置 svguest）— 2026-10-23

## 1. 解决什么问题

各分析模块默认产出 **PNG / SVG / PDF** 三套图：

- PNG：网页内联预览、汇报；
- SVG：矢量、文字可编辑，是二次排版的原件；
- PDF：投稿 / 印刷。

但「把多张结果图拼成一张组合图、加 A/B/C 面板号、统一字号、补比例尺」以前只能
导出到 Inkscape / Illustrator / GraphPad 里做。本次把 **svguest** 作为单文件静态应用
内置到平台，结果图可以直接在浏览器里完成这些整理，编辑与导出全程本地、不上传。

上游：<https://github.com/JieqiangHe/svguest>（GPL-3.0）
内置副本与改动说明：`webapp/static/vendor/svguest/SOURCE.md`

## 2. 入口

| 入口 | 位置 | 行为 |
| --- | --- | --- |
| 结果中心顶栏 | `/results` → `🎨 结果图整理` | 打开空白编辑器（可拖入 SVG/PNG，或菜单打开） |
| 结果中心组卡 | `/tools?g=result` | 同上 |
| 文件列表 | 样品结果「📁 文件」、专项运行文件、工具产物卡 | 每个 `.svg` / `.png` 行末的 `🎨 整理`：直接载入该图 |
| 图件预览 | KV 识别/定量、变异图、进化学图等 | `SVG` 下载 + `🎨 整理` |

`?open=<同源 URL>` 是平台给内置副本加的唯一补丁：

```text
/svguest/?open=%2Ftool_runs%2Fkv_demo%2Ffigures%2Ffreq_multi_metrics.svg
```

只接受**同源**地址；跨域 URL 会被忽略。SVG 以可编辑文档打开，PNG/JPG 作为图片
放到画布上（可继续画框、箭头、文字、比例尺）。

## 3. 编辑器能力（上游功能，未改动）

- 打开 SVG / 放置 PNG、JPG；多文档标签页；
- 矩形 / 圆 / 线 / 箭头 / 抑制箭头 / 折线连接 / 大括号 / 楔形 / 文字；
- 图层、分组、锁定、对齐分布、精确坐标与样式；
- FigKit：批量缩放、网格排版、面板号、边框、配色、比例尺、局部放大；
- 导出 SVG、PNG/JPG（300/600 dpi）、矢量 PDF（打印对话框）；
- 全部在前端完成，图形数据不出本机。

## 4. 绘图侧改动（让 SVG 真的存在）

以下模块的出图助手补上了 SVG（失败时只跳过 SVG，不影响 PNG/PDF）：

- `known_virus_suite/kv_fig.py`（丰度 / 共丰度）
- `known_virus_suite/kv_variant_plot.py`、`kv_variant_evo.py`（默认 `FIG_FORMATS`）
- `known_virus_suite/kv_plot.py`（per-virus 深度图）
- `toolbox_plots.py`、`public_meta/prescreen_plot.py`
- `public_meta/landscape_plot.py`
- `stage_funnel.py`、`sdt_exact.py`
- `conan_design.py`、`phylodyn_trees.py`（RootToTip）

`kv_fig` 的幂等条件也改成「PNG + SVG 都齐」：旧运行首次打开结果页时会补生成
一份 SVG，不需要重跑分析。

## 5. 路由与导航

- 路由：`Virus_Platform_Core/web/pages.py::page_svguest` → `/svguest/`
  （`send_file` 发送内置单文件，`Cache-Control: no-cache`）。
- 导航：`NAV_GROUPS` 的「结果中心」组新增
  `🎨 结果图整理（svguest）`；`_PATH_TO_GROUP` 登记 `/svguest/`。
- 前端助手：`webapp/static/app.js::svgEditHref / svgEditLink`，
  所有「整理」链接都经它拼 `?open=`。

## 6. 许可与分发

svguest 是 GPL-3.0。平台把它作为**独立静态页面**内置，不链接进平台源码；
`webapp/static/vendor/svguest/LICENSE` 与 `SOURCE.md` 随目录保留。

- 如果分发平台安装包：保留该目录及许可，遵守 GPL-3.0 的源码提供义务；
- 如果不想承担该义务：打包时排除 `webapp/static/vendor/svguest/`，把入口改为
  链接上游在线实例即可（导航卡与按钮仍可保留，只是 `?open=` 不可用）。

`dev_tools/VirusPlatform.spec` 用 `_tree(webapp)` 整目录打包，内置副本会自动
进入分发版；`dev_tools/dist_completeness.py` 的 `webapp` 完整性检查也会覆盖它。

## 7. 升级上游

见 `webapp/static/vendor/svguest/SOURCE.md`。升级后需确认：

1. `readFile()` 与 `msg()` 仍是全局函数（补丁依赖）；
2. `</body>` 前仍可追加脚本；
3. 末尾补丁仍存在，`?open=` 可用。
