## 0. 结论摘要

在「检测与防治」组新增 **CRISPR 检测试剂设计** 能力：以目标病毒参考序列集 + 宿主/近缘病毒排除库为输入，一次产出 **Cas12a crRNA 候选 × RPA（或 PCR）引物对** 的协同设计、复合评分排序、订购表与 L1–L5 实验验证清单。

- **不引入任何新外部工具**：MAFFT、ViennaRNA（`import RNA`，3rd/python 已内置 2.7.2）、primer3（primer3_runtime 已封装）、本地 BLAST + host-db、ICTV 参考获取（/refdata）全部复用现有设施。
- **算法规则来自六个开源工具 + PathoGD Nature 论文 Methods 的源码级提炼**，按平台许可状况做净室重实现（见 §1.2 许可红线）。
- 平台现有 dsRNA 模块（dsRNAmax 全链）已覆盖 FlyRNAi SnapDragon 的 RNAi 引物设计场景，仅补两个小选项（§3.8）。

### 1.2 许可红线（平台无 LICENSE 文件，按保守口径处理）

- **GPL-2.0（AutoCORDSv2）/ GPL-3.0（PathoGD）**：只借鉴算法规则与参数（规则本身不受版权保护），**不复制任何代码**。本文档中的规则表即净室规格。
- **无许可证（CASPER、CRISPRPrimerDesigner）**：默认保留所有权利。同样只参考公开描述的参数与思路，不复制代码。
- **MIT（RPA-Primer-Design）**：允许直接借用代码，但为保持平台依赖树干净，第一版仍采用净室实现，仅在文档与报告中引用致谢。
- 所有工具在模块报告的「方法与引用」段落中列出，用户导出报告时自动带上引用。

### 1.3 关键算法参数提炼（净室规格基础）

**crRNA 过滤漏斗**（合并 AutoCORDSv2 + PathoGD + CRISPRPrimerDesigner）：

| 步骤 | 规则 | 默认值 | 来源 |
|---|---|---|---|
| PAM 扫描 | 严格档 `TTT[ACG]`；容错档 = 前 3 位容 1 错配（4 组正则并集） | 严格档默认 | AutoCORDSv2 / CRISPRPrimerDesigner |
| PAM 优先级 | TTTA/TTTC/TTTG 记 +分，TTTT 记 −分（LbCas12a 对 TTTT 活性偏低） | 排序项 | PathoGD 论文 |
| 间隔区长度 | 20–24 nt，默认 20 | 20 | AutoCORDSv2(-cl) / CASPER |
| 保守性 | spacer 区平均逐列保守分 ≥ 阈值 | 0.95（高变异 RNA 病毒可放松至 0.85） | AutoCORDSv2(-cct 0.99，病原通量下太紧) |
| GC 含量 | 30–70%（排序钟形最优 40–60%） | 30–70% | AutoCORDSv2 / CASPER |
| 同聚物 | poly-N ≥5 剔除；poly-T ≥4 即标记（T7 转录终止风险，Cas13a 路线必检） | ≥5 剔除 | PathoGD / 通用 |
| 二级结构 | crRNA（含 handle 语境）RNAfold MFE ≥ −5 kcal/mol | −5 | AutoCORDSv2 |
| seed 区特征 | PAM 近端 5–8nt 的最大 run、GC、（可选）未配对比例 | 排序项 | CASPER |
| 基因组内唯一性 | 同基因组其他位置 ≤k 错配命中数 | k=3 报告、k=0 可选硬过滤 | CRISPRPrimerDesigner（cas-offinder 语义） |

**RPA 引物过滤漏斗**（合并 MangoBank + CRISPRPrimerDesigner + AutoCORDSv2 + CASPER）：

| 步骤 | 规则 | 默认值 | 来源 |
|---|---|---|---|
| 长度 | 28–35 nt（primer3 OPT 30–32） | 30–35 | 四家一致 |
| GC | 30–70%（排序钟形 40–60%） | 30–70 | 四家一致 |
| 产物长度 | 100–200 bp（高变异 RNA 病毒可放宽到 80–500） | 100–200 | MangoBank / PathoGD(90–300) |
| Tm | primer3 口径 60–70（OPT 65）；ΔTm(正向,反向) 越小越好 | — | CRISPRPrimerDesigner / CASPER |
| 3' 端 | 无 ≥3 同碱基 run；3' 最好 G/C（GC clamp 1） | run ≤2 | CASPER（3p_self_run ≤2 硬过滤） |
| 同聚物/富 G | 无 G6/C6；PRIMER_MAX_POLY_X 生效 | — | AutoCORDSv2 / primer3 |
| 二聚体/发夹 | primer3 SELF_ANY/SELF_END/PAIR_COMPL + RNAfold DNA MFE ≥ −5 | MFE ≥ −5 | CRISPRPrimerDesigner / AutoCORDSv2 |
| 保守性 | 引物区平均保守分 ≥ 阈值 | 与 crRNA 同参 | AutoCORDSv2(-pct) |
| 探针（可选） | EXO：5′ 加 `FAM-TGCGT-…-BHQ1` 骨架；NFO：3′ `…-C3-spacer` + 中部 ABII Q；30–35nt，Tm 比引物高 2–5℃ | 关闭 | MangoBank |

## 2. 与 ACS Sensors 框架的映射

本模块是综述第 4 层「计算设计支持」的植物病毒实例化；综述反复强调的边界直接写进产品行为：

1. **输出即证据边界声明**：每份结果报告首部固定注明「计算设计仅支持候选优先级排序，不构成 crRNA 活性、错配区分度、扩增兼容性或基质性能的证据」；对应综述 L1–L5 五级证据链，报告尾部生成植物病毒语境的验证清单（§3.7）。
2. **瓶颈迁移决策树**（综述 Table 1）做成设计页的辅助面板：灵敏度不足→优先查靶标可得性/预扩增，而不是盲目换 crRNA；区分度不足→优先 intentional mismatch 与近缘种排除库，等等。帮助用户把实验迭代指向真正的瓶颈层。
3. **群体覆盖 vs 近缘区分的权衡显式化**（PathoGD 黄病毒先例）：高变异 RNA 病毒群体覆盖阈值的每次放松都会以近缘区分度为代价，界面把两个指标并排展示并允许用户拖动阈值实时看候选数量变化。

## 3. 模块详细设计

### 3.1 总体数据流

```
输入
├─ 目标序列集：多分离物 FASTA（≥1；推荐 ≥10，来源可用 /refdata 一键拉取 ICTV 科/属代表）
├─ 排除库（两路，均可选但强烈建议）
│   ├─ 宿主基因组：host-db 现有植物宿主库（kunpeng 分类库直接复用）
│   └─ 近缘病毒：本地近缘种 FASTA（/refdata 下载或用户上传；默认含常见复合侵染毒源）
└─ 参数：Cas12a（默认）/预留 Cas13a；RPA/PCR；各阈值

管线（新 Core 模块，全部离线）
① MSA：MAFFT（已有，复用阶段⑦通道）→ 逐列保守分 + 多数共识（majority，含歧义码）
② 候选 crRNA 生成：共识序列双链扫 PAM → §1.3 crRNA 漏斗 → 候选池
③ 候选引物生成：每个 crRNA 位点取侧翼窗（默认 ±250bp）
   → 路线 A：primer3（primer3_runtime 已有，RPA 参数模板）取 top-N 对
   → 路线 B（引物数不足时自动兜底）：滑动枚举 28–35nt 全组合按漏斗过滤（AutoCORDSv2 语义）
④ 特异性双库筛查：候选 crRNA/引物 vs 宿主库 + 近缘病毒库
   - 短序列比对用本地 BLAST（task blastn-short 参数）或复用 dsrna_offtarget 的
     2-bit k-mer 二分扫描器（mm0→mm1→mm2 分层，21nt 口径；该扫描器已过 blastn 对拍）
   - crRNA：seed 区（PAM 近端 ~8nt）内命中 = 一票否决；远端错配 ≥3 视为安全（PathoGD 口径）
   - 引物：3' 端 10nt 内命中 = 一票否决；整链 ≥30% 错配率（AutoCORDSv2 -pst 语义）
⑤ 配对与复合评分：§3.4 CASPER 式效用评分 → 排序
⑥ 群体覆盖率回填：top 候选回扫全部输入分离物（含容 1–2 错配），报告覆盖 % 与未覆盖株列表

输出（§3.7 契约）
```

### 3.2 crRNA 设计引擎（净室规格）

- PAM 上下文连同直接重复序列（DR/handle）一起输出：`LbCas12a` 默认 handle `UAAUUUCUACUAAGUGUAGAU`，输出列同时给「spacer-only（化学合成）」与「DR-spacer（T7 体外转录，自动前置 T7 启动子并做 poly-T 检查）」两种订购格式——后者直接服务 Cas13a/one-pot 路线（PathoGD 论文明确此适配方式）。
- 长度扫描：默认 20nt，同时给 21–24nt 的相邻候选（同一 PAM 位点多长度并评，CASPER 上限 24）。
- intentional mismatch（综述 §guide engineering）：当用户勾选「近缘区分优先」时，对近缘库中唯一错配位点在 spacer 内的候选做定点错配建议（给出错配位置 + 该位点在近缘种中的碱基），并标注综述警告——该策略序列与位置依赖，必须实验验证区分度增益与活性损失。

### 3.3 RPA 引物设计引擎

- 主路线 primer3 参数模板（继承 MangoBank/CRISPRPrimerDesigner 净室参数）：

```python
RPA_P3_GLOBAL = {
    'PRIMER_OPT_SIZE': 31, 'PRIMER_MIN_SIZE': 30, 'PRIMER_MAX_SIZE': 35,
    'PRIMER_OPT_TM': 65.0, 'PRIMER_MIN_TM': 60.0, 'PRIMER_MAX_TM': 70.0,
    'PRIMER_MIN_GC': 30.0, 'PRIMER_MAX_GC': 70.0,
    'PRIMER_GC_CLAMP': 1,
    'PRIMER_MAX_POLY_X': 4, 'PRIMER_MAX_SELF_ANY': 8, 'PRIMER_MAX_SELF_END': 4,
    'PRIMER_PAIR_MAX_COMPL_ANY': 8, 'PRIMER_PAIR_MAX_COMPL_END': 4,
    'PRIMER_MAX_HAIRPIN_TH': 20, 'PRIMER_MAX_NS_ACCEPTED': 0,
    'PRIMER_PRODUCT_SIZE_RANGE': [[100, 200]],
    'PRIMER_NUM_RETURN': 5,          # 每个 crRNA 位点最多 5 对（PathoGD 口径）
}
```

- 引物相对 crRNA 的位置约束（CRISPRPrimerDesigner 语义）：扩增子必须完整包含 protospacer+PAM，且 crRNA 位点距扩增子任一端 ≥30bp（避免扩增子太短影响 RPA 效率与侧流判读）。
- PCR 模式直接复用 `primer_design.CORE_DEFAULTS`，与现有 /primer 页参数一致，保证两条路径可比（对齐 primer.py 合并的历史教训）。

### 3.4 配对与复合评分（CASPER 式，初始权重）

对每个「crRNA × 引物对」组合计算 21 项特征，加权效用求和（权重合计归一）。**权重来自 CASPER 拟合 100 组实验对的公开配置，作为初始值；平台报告注明其训练数据局限（iGEM 项目，非植物病毒体系），二期可用平台用户实验反馈重拟合。**

| 类别 | 特征（权重） | 效用函数要点 |
|---|---|---|
| 脱靶（0.29） | crRNA/正向/反向错配加权命中（0.08/0.07/0.07） | exp 衰减，best=0，half-life=1 |
| 二聚体（0.33） | 正/反自二聚 %、交叉二聚 %（0.1×3） | 线性衰减 L=50，H 自适应 95 分位 |
| 3' 端稳定（0.14） | 正/反 3' 自身 run、交叉 run（0.045/0.045/0.05） | exp 衰减 |
| Tm 平衡（0.14） | ΔTm（0.08）、正/反 Tm（0.03×2） | ΔTm 拉普拉斯 t=0 s=1.5；Tm 平台 55–65 |
| GC（0.075） | 正/反 GC（平台 40–60）、扩增子 GC（平台 35–65） | 平台函数 falloff=10 |
| 种子与结构（0.105） | seed 最大 run、seed GC、crRNA MFE、seed 未配对比例 | 线性/平台混合 |
| 交叉干扰（0.04） | 引物与 protospacer/PAM 重叠 | 线性衰减 |

（实现落在纯 numpy，特征计算口径照 CASPER 公开描述净室复刻；二聚体 % 用简化互补配对口径并在帮助页写明定义。）

### 3.5 特异性双库筛查

- **宿主库**：直接复用 `host-db/host/classify`（kunpeng 分类库，含植物转录组/CDS）；有基因组 FASTA 的宿主（/build 可下载）优先用全基因组，否则用 CDS 集。植物粗提液检测的最大风险就是宿主核酸背景放大，这一路是植物场景相对人类病原工具的**实质增量**（六个调研工具均无人类以外宿主库概念，PathoGD 排的是人基因组）。
- **近缘病毒库**：同属/同科代表序列（/refdata ICTV 拉取或用户上传）+ 常见复合侵染病毒清单（可内置一个种子清单放 `databases/crispr/near_neighbors/`）。
- 扫描实现优先复用 `dsrna_offtarget` 的排序数组扫描器（改造成 20–24nt 窗），BLAST 作交叉验证；红线注释（mm 分层顺序、双链入集等 5 条）原样继承。

### 3.6 植物病毒特化处理

1. **多分体基因组**：输入按 segment 分记录（RNA1/RNA2/…），全流程按 segment 独立设计，输出表带 segment 列；支持「按 segment 出多套试剂」与「跨 segment 出 panel」两种汇总视图。
2. **高变异 RNA 病毒放松档**（PathoGD 黄病毒先例）：预设「严格/放松」两档参数包——放松档：保守阈值 0.99→0.85、允许 majority 共识含歧义码（R/Y 等，引物设计自动避让歧义位）、产物上限 200→300、群体覆盖阈值 90%→50%，并联动显示近缘区分度损失。
3. **Cas13a 输出格式**（二期）：Cas13a 无 PAM 依赖（PFS 宽松），spacer 直接取保守窗；T7-crRNA 订购序列自动生成 + poly-T ≤3 硬检查（T7 转录终止）。对 RNA 植物病毒可走「免逆转录直接测 RNA」路线，在报告里作为方案选项提示。
4. **现场部署语境**：RPA 37–42℃ 等温、侧流试纸判读、粗提液（Whatman 纸片/碱裂解）基质——这些进 L1–L5 清单的措辞（§3.7），不进算法。

### 3.7 输出契约（对齐平台样品目录契约风格）

结果目录 `NN_crispr/`（工具任务落 `run/tool_runs/`，挂结果中心）：

```
NN_crispr/
├─ crrna_candidates.tsv     # 全部候选明细（21 特征 + 各漏斗指标 + 覆盖率 + 排除库命中详情）
├─ ranked_sets.tsv          # top 组合：crRNA(DR-spacer/spacer-only/T7 三格式) × 引物对 × 探针 × 评分分解
├─ order_sheet.xlsx         # 订购表（合成引物 + crRNA，含修饰与 5′/3′ 标注）
├─ report.html              # 可视化：基因组位点图 + 保守性轨道 + 候选位置 + 覆盖率条形 + 评分雷达
├─ validation_checklist.md  # L1–L5 植物病毒语境验证清单（附证据边界声明，见 §2）
└─ crispr_design.json       # 全参数快照（复现用，reproducible 口径）
```

L1–L5 清单（植物病毒语境，随报告自动生成）：
- **L1 纯化靶标**：合成含 protospacer 的 dsDNA/ssDNA 或体外转录 RNA，测 aLoD、time-to-positive、crRNA 活性初筛；
- **L2 加标基质**：健康植株粗提液（纸片提取/碱裂解两种前处理各做）加标梯度，测回收率与抑制；必须包含近缘病毒核酸加标以测交叉反应；
- **L3 回顾性样本**：平台历史阳性样品（可直接从本平台 02_kvsuite 定量结果召回样本清单）盲测，以 RT-qPCR 为对照算一致性；
- **L4 前瞻性田间**：多地点、多品种、不同生育期，操作者非开发者；记录每位点 20 分钟内出结果比例；
- **L5 实际使用**：田间站/检测点实际人员操作，储存稳定性（37℃ 加速 / 常温运输）、批次一致性、单样成本、结果的处置决策记录。

### 3.8 RNAi/dsRNA 引物设计对照结论（FlyRNAi 项）

平台现有 dsRNAmax 全链（选窗→siRNA 效价→脱靶→Primer3 T7 引物→成品 QC）在设计核心上**已超过** SnapDragon（其不做 siRNA 效价评分）。仅吸收两个界面/选项级补充：
1. **脱靶匹配长度可调**（SnapDragon 16–50bp 概念）：`dsrna_offtarget` 扫描口径目前固定，可在工具页暴露为参数（默认保持现值，改动需重跑对拍验证）；
2. **克隆酶切位点追加**：SnapDragon 的 19 种内切酶选项 → dsRNA 引物输出增加可选 5′ 酶切位点（默认无，仅影响订购表，不影响打分）。
两项均为小改动，随 CRISPR 模块同期实施即可。
