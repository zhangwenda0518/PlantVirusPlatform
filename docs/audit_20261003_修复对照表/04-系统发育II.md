## 未修复项 + 原因

1. **项 12（P2，报告 R² 文案）**：工作区文本已是修复后状态（表头「R²（时钟拟合, TreeTime 口径）」+
   「R²（DRT 最大根位）」+ 不可比说明），`git diff` 显示该改动非本次会话所做 → 未改（已符合），无遗留。
2. **项 8 的"`phylodyn_kit.attach_coords` 同步"**：逐行读该函数 —— 它只做区划名匹配并原样复制坐标，
   **不做任何逐轴平均**，因此没有"同源处"可改（真正的质心计算只在 phylogeo 的
   `coord_table_centroid`/`resolve_region_positions`，已修）→ 未改 + 依据如上。
3. **附加发现（不在清单内，未改）**：`phylodyn_trees._parse_translate` 的正则要求每条翻译项后跟
   `[,;]`，而它用非贪婪 `translate\s+(.*?);` 截出的块**不含结尾 `;`** → 最后一条翻译项永远不命中
   （合成文件实测 `3 → tipC` 未生效，`1/2` 生效，新旧实现行为一致）。真实 BEAST 输出通常
   "最后一项 + 换行 + `;`"，同样落在括号外，属既存缺陷；修复需要重写 Translate 解析（超出本清单、
   且本机暂无真实 .trees 可复核）→ 未改，建议单列一项处理。
4. **附加发现（不在清单内，未改）**：`phylodyn_trees._root_candidate_set`（随机化树写出时的根候选集）
   仍用旧的"两两求交"up-pass，与项 2 修后的 `_fitch` 在多叉节点上口径不一致。它只影响
   `randomize_test` 落盘随机树的 `root_set` 注解（不影响统计量），且不在本清单 → 未改，如需一致
   可按项 2 同法改（3 行）。
5. **`docs/*.md` 历史文档**（`进化动力学双份对比_20260917.md` 等）提到 `ltt_and_skyline`：属 2026-09-17
   的历史对比快照，未回改（删除处已在代码里留注释指向 git 历史）。
