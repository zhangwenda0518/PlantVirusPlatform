## 一、发现并修复的缺陷（按严重度）

### P0-1 `TaskLogger` 缺 logging.Logger 风格方法 → salmon 引擎 ②b 阶段必崩
- **现象**：CLI 全流程实测中，②b「抽病毒 reads」收尾即崩：
  `AttributeError: 'TaskLogger' object has no attribute 'warning'`。
- **根因**：`kv_stage.py:631` 的「BAM 无真实质量值」告警分支按 `logging.Logger`
  习惯调 `logger.warning(...)`，而流水线传入的是自研 `TaskLogger`（只有 `.log()`）。
  salmon 的 BAM 恒无 QUAL → **该分支每次 salmon 运行必踩**，②b 之后全流程无法进行。
- **修复**：`Virus_Platform_Core/utils.py` — `TaskLogger` 补齐 `info/warning/error/debug`
  四个便捷级（鸭子类型兼容 logging.Logger；debug 不落盘）。
- **回归测试**：`tests/test_utils_pure.py::test_tasklogger_logger_style_levels`。

### P0-2 `sdt` colormap KeyError → SDT / identity / 比较三处全崩（mpl 3.9+ 迁移回归）
- **现象**：`_it_compare` 与 `_check_identity_aa` 双双挂在
  `KeyError: "'sdt' is not a valid value for colormap."`。
- **根因**：`sdt_exact._cmap_colors` 从 `plt.get_cmap`（抛 ValueError）迁移到
  `matplotlib.colormaps[name]`（抛 KeyError）后，except 子句没跟上——
  `'sdt'` 本就是自造名（经典红黄色阶 `SDT_COLORS` 是权威色值，靠回退分支兜底），
  回退整条失效。
- **修复**：`sdt_exact.py` except 扩为 `(KeyError, ValueError, TypeError)`。
- **验证**：两个测试复跑即绿（一处修复救活两条链路）。

### P1 流程漏斗两层单位不一致 → 留存率虚高 2 倍
- **现象**：真实全流程（cli_fulltest）漏斗显示「输入 reads 166,436」→
  「去宿主后 reads 330,632」，环比 198%。
- **根因**：无 fastp 时输入层回退读 `01_host_removal/stats.json` 的 `total_pairs`
  （**对**），而下一层 `_x_host_free_reads` 返回 `kept_pairs×2`（**条**）。
  同一漏斗混用单位；且单端（SE）时 `kept_pairs` 本就是单条 reads（host_removal
  的 `kept1=R1 记录数`），原实现也无条件 ×2。
- **修复**：`stage_funnel.py` — 双端 ×2 折条、单端不乘；note 去掉自带括号
  （图函数会再包一层，此前出「（（对×2 估算））」双括号）。
- **回归测试**：`test_stage_funnel.py` 新增 `test_single_end_units_not_doubled` +
  输入层回退断言。修复后实测留存率 99.33% 与宿主占比 0.67% 严格吻合。

### P2-1 i18n 4 个键未定义（英文界面露中文）
- `tk.rdpThR / tk.rdpThMaj / tk.rdpThMin / tk.rdpThMethods`（RDP5 断点分布
  tooltip 用）在 tools.html 使用但中英字典均未定义。已补 zh/en 各 4 条。
- 由新入编的 `_audit_contract.py`（跨层契约审计）实抓。

### P2-2 toolbox_plots 多面板直方图 8 处文字重叠
- **现象**：图形体检（check_figures 引擎）实抓 `"65"×"-0.5"` 161px² 等 8 处 FAIL
  （`plot_align_qc` / `plot_crispr`）。
- **根因**：相邻面板的**最外侧底部刻度**悬在面板边界外的同一行——
  tight_layout 的横向间距计算不含底部刻度的横向外溢。
- **修复**：`toolbox_plots._multi_hist` 统一 `MaxNLocator(prune='both')`
  剪掉两端最外刻度（撞的正是这两个），另给 4 处多面板 tight_layout 加 `w_pad`。
- **验证**：13 个绘图函数复检 **0 FAIL**；目检观感无退化。

### P3 留存率图把非零极小值显示成「0%」
- 病毒 contigs 2/7200≈0.03% 四舍五入后显示「0%」，有误导。
- `_pct` 增加 `0 < x < 0.05 → '<0.1%'` 分支；fixture 图同步重生成。
