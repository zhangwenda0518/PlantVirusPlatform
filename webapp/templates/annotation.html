🧾 功能注释

独立模块：ORF 蛋白对照 RefSeq 病毒蛋白库 （DIAMOND / MMseqs2 / blastp 任一，自动探测）+ 类别投票 + ICTV 映射。 可对已有「ORF 预测」运行直接注释，也可输入 FASTA 一步完成 （预测 + 注释）。首次运行自动下载 RefSeq 病毒蛋白库 ~107MB，之后全缓存。 CDS 基因模型默认 pyrodigal-rv（RNA/反转录病毒），可按需切换 pyrodigal （meta 基因模型）。

层1 做 DIAMOND/MMseqs2/blastp 同源搜索（首次会下载 ~107MB 参考库）；层2 Pfam HMM 与 BFVD 病毒域为本地库、无需下载（BFVD 与 NCBI 提交链同库，product 命名一致）。只勾层2 时可跳过层1，速度快很多，但不会有 物种/科属与类别投票结果。

方式 A · 对已有 ORF 运行做注释

方式 B · 输入 FASTA（预测 + 注释一步完成）

可直接 Ctrl+V 粘贴多行 FASTA / 纯序列；文本框右下角可拖拽放大。文本框与上方文件路径二选一，文本框优先（无需先落到文件）。
📤 输出

产物（运行目录 orfa_ 开头 / 结果中心可查）： orf_annotation.tsv、功能类别 / 科分布、注释 GFF3。
