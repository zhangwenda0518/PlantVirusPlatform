🛰 MCP 控制台

平台通过标准 MCP（stdio）暴露全部 vp_* 工具：内置 AI 助手用的就是这一层，外部 agent（Claude Desktop / Cursor / VS Code 等）也可以接入同一套契约。本页是调试面板——手填参数、看原始返回。

连接

打开本页会自动连接内置 mcp_server（stdio，标准 MCP 协议）并列出全部工具；首次连接较慢（要导入平台模块）。工具清单由服务器实时返回，本页不写死数量。

run_tool / pipeline_start / cli_submit 返回 task_id 后，再调 get_task 轮询；task/call 类参数记得读 vp_list_tools / vp_cli_help 的 schema。
