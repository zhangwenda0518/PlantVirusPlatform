🧬 宿主基因组下载（→ 构建宿主库）

宿主去除（工具①）和宿主预测（工具④）都要宿主库。三源可选： gget·Ensembl（覆盖水稻、番茄、小麦等 NCBI 之外的植物宿主）、NCBI taxon（按物种）、 NCBI accession（按组装号精确下载，可染色体过滤）。产物落到 host-db/<TaxID>_<物种>/genome.fa， 下载完成后去「数据库构建」页点「构建宿主库」即可（路径 TaxID 自动解析）。 gget 需先安装：pip install "gget==0.30.5"；accession 模式需 datasets CLI（python main.py datasets-setup）。

🦠 NCBI datasets 病毒数据集（→ 病毒库构建）

按病毒 taxon（可加宿主过滤）拉取 NCBI 病毒基因组，自动产出 reference.fasta + reference.ref_info.tsv（含 Taxid/宿主/地理列），落 databases/virusref_db/<名>/，「数据库构建」页「原始数据集」卡即时识别——一键建鉴定库索引或 kunpeng 分类库。 需 NCBI datasets CLI（未装时执行 python main.py datasets-setup 自动安装）。

📥 NCBI datasets 通用下载（genome / gene / taxonomy）

datasets CLI 其余模式：任意物种基因组包（taxon / accession+染色体过滤）、 基因包（gene-id / symbol+taxon / 蛋白 accession）、分类报告包。产物落 datasets_dl/， 供注释、比对、建树等下游自取。旧版 --exclude-* 语法已自动翻译为 --include 组合。
