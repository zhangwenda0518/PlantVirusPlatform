🏠 样本处理

⚡ 一键前处理（SRA / FASTQ 自适应）

.sra：SRA→FASTQ → 质控 → FASTQ→FASTA → 宿主去除； .fastq：质控 → FASTQ→FASTA → 宿主去除。宿主库未就绪自动跳过宿主去除、 fastp 未安装自动跳过质控，其余步骤照常。转换出的 FASTA 仅作分类加速输入， kept reads 仍从 FASTQ 提取（kept_*.fastq.gz，可直接喂「②→③→④ 一键流程」或样品管道）。

产物收拢到 tool_runs/prepchain_*/（kept reads + FASTA + 各步运行链接）

⓪ 格式转换（SRA / FASTQ / FASTA）

🛡 候选序列验证

对候选 contig 做宿主筛选 → 长度分流 → 双路过滤： ≥1000 bp 走病毒支（DIAMOND blastx + mmseqs2 BFVD 病毒域，取并集或交集）； 250–1000 bp 走类病毒支（blastn vs 类病毒库）。 过滤器语义：未命中（no-hit）保留为 unclassified——那是新病毒 / 新类病毒候选池， 不会当「排除」。

类病毒判定：identity ≥80% 且覆盖 ≥60%（250–300bp 放宽到 ≥40%）

🔁 RDP5 重组分析

RDP5 九方法检测（RDP / GENECONV / Bootscan / MaxChi / Chimaera / SiScan / PhylPro / LARD / 3Seq），本机原生运行。用于「同种 / 同株系」病毒的重组检测——输入为这组同源序列的比对 FASTA（跨病毒比较请用「序列比对」卡）。

⚠ 序列集须来自同一病毒（同种 / 同株系），如 Explorer 里同一病毒的多条分离物；不同病毒之间不存在「重组」，那种比较请走「序列比对」。

进 RDP5 前先剔除不完整序列，口径同参照管道 align_qc：长度比 < 0.90、gap > 10%、N > 5%（只在填了参考 ID 时才判「与参考 identity 偏离 > 2%」）。剔除明细见运行目录 align_qc_report.tsv。

RDP5 命令行不产出基因坐标；可从 GenBank 注释抄 CDS 起点/终点（按参考序列，即 qc_ref 或比对首条），平台自动映射到比对坐标。

RDP5 九方法检测，逐方法 p 值；坐标为比对列位（1-based）

⚠ 方法学提醒：迁移方向与根位置的重建，在方向性扩散（单向跨区扩张）或缺历史/古样本时误差更大、HPD 覆盖率也会偏离名义值；任何方向性结论请先确认下方 RRT 是否显著（依据：drifting_into_nowhere 仿真，27 仓解读报告 E1 段）。

🧬 进化动力学数据接入

三个来源建标准数据集（FASTA + 元数据 name,date,location[,lat,lon]），时间与地点必须同时给出、格式必须正确（YYYY / YYYY-MM / YYYY-MM-DD）。产出可直接喂给时间信号 / 系统地理 / TreeTime 等卡。

输出与平台元数据**完全一致**（name,date,location[,lat,lon]，GenBank 带 host 时追加一列 host）；地点优先取 geo_loc_name（保留到省/市）。RefSeq 参考记录常缺时间/地点，会被自动跳过（报告里逐条列出），所以实际会多取一些再挑。
⚙️ 可选后处理（默认不做；展开才需要勾）
不勾任何项 = 最简流程：导入 → 元数据治理（自动）→ 概览出图（自动）→ 「接力 A0 全链」。下面的开关按需勾：三元组去重（无损）、比对质检（可先 MAFFT）、区域坐标表、时空降采样（有损）。
治理只归一与标注（占位符/未知地点**清空该字段、不丢行**，逐条计入报告）；QC 会按 长度≥90% / gap≤10% / 简并≤5% / identity 不异常 剔除不合格序列，并另存 clean/removed。A0 的全链要求**等长比对**。
给地图落点；不给就用内置质心表（常见国家/大洲，近似）
「各分区等量」按最小区划的条数取样，结果可能很小；没有区划信息的样本（Unknown/空）会被排除并如实报告。降采样后产物另存为子集，原数据集保留。
